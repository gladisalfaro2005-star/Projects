# Proyecto de Computer Vision

Este repositorio contiene las prácticas de la unidad 1 y 2.

##  Instrucciones para ejecutar el código

1. Abre la carpeta de la unidad que quieras revisar (por ejemplo, `unit2/src`), ahi se encuentran los códigos .py.
2. Asegúrate de instalar las librerías necesarias.
3. Ejecuta el archivo principal: `python main.py`
